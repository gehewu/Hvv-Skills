# 边界设备与高频靶标（护网补充）

> 护网外网打点的高价值目标往往不是业务 Web，而是 **VPN / OA / 邮件 / 网关 / 域控 / 中间件管控台**。
> 本文只讲“怎么识别、怎么低特征验证、怎么报备”，不展开破坏性利用。
> 所有动作必须在授权清单内；触碰核心设备前先报备。

---

## 1. 为什么先打边界

- 边界设备一旦拿下，直接进内网，价值远高于单个业务站
- 边界设备常被忽视、补丁滞后、默认配置多
- 护网靶标常包含“边界突破”这一档

**顺序：** 识别 → 指纹/版本 → 默认配置/未授权 → 已知漏洞（有 PoC）→ 弱口令（少量）→ 报备利用

## 2. 常见设备与入口

### 2.1 VPN / SSL VPN
| 产品 | 识别特征 | 常见问题 |
|------|----------|----------|
| Fortinet FortiGate | `FortiGate`、`/remote/login` | 已知 CVE、弱口令、SSL VPN 未授权 |
| Pulse Secure | `/dana-na/` | 已知 RCE、路径穿越 |
| Cisco ASA | `ASA`、`/webvpn/` | 已知漏洞、默认口令 |
| Sangfor 深信服 | `SSL VPN`、`/por/login` | 弱口令、已知漏洞 |
| OpenVPN | `OpenVPN`、1194 | 配置泄露、证书 |
| Citrix NetScaler | `/vpn/`、`Citrix` | 已知 CVE、未授权 |

**验证：** 登录页指纹 → 版本接口/静态文件 → 已知 CVE 检测（只读）→ 默认口令少量尝试（按 ROE）→ 报备。

### 2.2 OA
| 产品 | 识别 | 常见问题 |
|------|------|----------|
| 泛微 e-cology | `/wui/`、`ecology` | 未授权、SQLi、RCE、文件上传 |
| 致远 A8 | `/seeyon/` | 未授权、XXE、RCE |
| 蓝凌 | `/km/`、`landray` | 未授权、SQLi |
| 通达 | `/general/` | 未授权、文件包含 |
| 华天动力 | `/OA/` | 未授权、SQLi |

**验证：** 指纹 → 未授权接口 → 已知漏洞只读验证 → 弱口令少量 → 报备。

### 2.3 邮件
| 产品 | 识别 | 常见问题 |
|------|------|----------|
| Exchange | `/owa/`、`/ecp/` | ProxyLogon/ProxyShell、SSRF、EWS |
| Coremail | `Coremail`、`/coremail/` | 已知漏洞、配置泄露 |
| 亿邮 | `eyou` | 已知漏洞 |
| Zimbra | `/zimbra/` | 已知 RCE、XXE |
| Postfix/Dovecot | SMTP/IMAP banner | 开放中继、弱口令 |

**验证：** OWA/管理入口 → 版本 → 已知 CVE 只读检测 → 不群发、不钓鱼（除非 ROE 允许）。

### 2.4 网关 / 反代 / 负载
- F5 BIG-IP（`/mgmt/tm/util/bash` 等管理面）、Citrix、Nginx、Kong（8001 admin）、APISIX（9180）、Spring Cloud Gateway（actuator/gateway）
- 重点：管理面未授权、actuator 暴露、路由配置泄露、SSRF 跳板

### 2.5 域控 / 身份
- AD / LDAP / Kerberos / ADFS / CAS / OAuth
- 高风险动作（DCSync、黄金票据、Zerologon、PetitPotam）**必须报备**
- 只做“证明可达/可读”的验证，不破坏域

### 2.6 中间件 / 运维管控台
| 组件 | 端口/路径 | 风险 |
|------|-----------|------|
| Nacos | 8848 | 未授权、默认口令、配置泄露 |
| Apollo | 8070 | 未授权、配置泄露 |
| XXL-Job | 8080 | 默认口令、RCE |
| Jenkins | 8080 | 未授权、脚本控制台 |
| GitLab | 80/443 | 未授权、已知 CVE |
| Zabbix | 80 | 默认口令、SQLi |
| Grafana | 3000 | 默认口令、已知 CVE |
| Kibana / ES | 5601 / 9200 | 未授权、数据泄露 |
| Redis | 6379 | 未授权、写文件 |

**原则：** 先看是否公网可达 → 未授权/默认口令 → 只读证明 → 报备深入。

## 3. 低特征验证方法

- 不用全量扫描器；用定向请求、单路径、低频率
- 先看首页/静态文件/banner，再打具体接口
- 默认口令只试 1～2 个（按 ROE），不字典爆破
- 已知 CVE 用只读 PoC（读文件/回显），不上传、不执行命令
- 触发告警立即停，报备后再定

---

## 4. 报备与边界

- 触碰 VPN/OA/邮件/域控/数据库/核心系统前，按 `../hw-rules/collaboration.md` 报备
- 拿到权限后先固化证据，再决定是否深入
- 不修改设备配置、不创建账号、不留后门（除非报备）
- 不攻击第三方托管/云厂商基础设施

## 6. 一句话

**边界设备先识别、只读验证、少量尝试、动作前报备；拿下先固化，不破坏、不留痕。**
