# 护网协同、交接与报备

> 护网是团队行动：信息不共享会重复打、动作不报备会出事故、交接不清会断线。
> 护网**必须**在关键节点同步，但同步不是停工。

---

## 1. 角色与分工

| 角色 | 职责 |
|------|------|
| 带队人 / 主控 | 范围、节奏、报备、资源协调、对外沟通 |
| 外网打点 | 资产测绘、Web/API 打点、入口突破 |
| 内网 | 提权、横向、域渗透、权限维持 |
| 取证/报告 | 证据整理、报告撰写、时间线 |
| 蓝队值守 | 告警研判、应急、溯源、整改 |

小团队可一人多角，但**报备与留痕不能省**。

---

## 2. 线程 / 小组交接

每个子线程或新窗口开工前，先读/建 `协同\线程必读.md`：

```markdown
# 线程必读
- 行动名 / 角色 / 时间窗口
- 授权范围摘要（不要贴凭据）
- 当前靶标与状态
- 已覆盖资产（covered_hosts）
- 已知入口 / 权限 / 阻塞
- 本轮任务与边界
- 报备要求
- 交付物
```

子线程交付必须包含：

1. 做了什么（目标、动作、结果）
2. 证据编号
3. 新发现的资产/接口/凭据线索（脱敏）
4. 阻塞与建议
5. **迭代**：可复用的打法/教训（按 `references/hw-rules/workflow.md` 的复盘要求）

子线程完成后写 `协同\DONE.md` 一行：`靶标 | 状态 | 证据 | 拟进/拟补/不进`。

## 3. 何时必须报备

| 动作 | 报备时机 |
|------|----------|
| 提权成功 | 执行前或成功后立即 |
| 横向到新网段/新主机 | 执行前 |
| 域渗透高风险（DCSync/黄金票据/改策略） | 执行前 |
| 留后门/持久化 | 执行前 |
| 触碰核心系统/数据库 | 执行前 |
| 大规模扫描/可能触发告警 | 执行前 |
| 社工/钓鱼 | 执行前 |
| 越界/误触 | 立即，不隐瞒 |
| 靶标达成 | 立即 |
| 被封/被监测 | 立即 |
| 范围存疑 | 停手后立即 |

**报备模板：**

```
【报备】行动名 / 小组
目标：<靶标/URL/IP>
动作：<提权/横向/后门/…>
依据：<授权范围/ROE 条款>
风险：<生产影响/告警/数据>
计划：<步骤/回滚/清理>
请确认：可执行 / 需调整 / 禁止
```

## 4. 节点同步（不是停工）

以下节点**主动同步**，但同步后继续做范围内可做的事，不空等：

- 靶标达成 → 交证据、领下一个靶标
- 靶标 blocked → 说明原因，换下一个
- 发现高价值路径 → 同步，避免重复/冲突
- 被封/被监测 → 同步，调整节奏
- 时间窗口变化 → 同步，调整计划

**禁止：**
- 用“要不要继续”当停工理由
- 闷头打、不报备、不共享
- 重复打队友已覆盖的资产（先读 covered）
- 把凭据/会话发到群里（用加密台账/私聊）

---

## 5. 信息共享分级

| 级别 | 内容 | 共享方式 |
|------|------|----------|
| 公开 | 靶标状态、进度、阻塞 | 群/日报 |
| 内部 | 资产清单、接口清单、路径图 | 任务根/协同文件 |
| 敏感 | 凭据、会话、个人信息 | 加密台账/带队人 |

---

## 6. 与蓝队/指挥部沟通

- 红队：只报“授权范围内的事实 + 证据 + 影响”，不夸大、不隐瞒
- 蓝队：告警研判结论要带证据（日志/流量/主机），不只说“疑似”
- 对外：统一由带队人/指挥部发言，个人不擅自披露

---

## 7. 冲突处理

- 两个小组打同一目标 → 以靶标队列负责人为准，另一组转支援/换目标
- 红蓝对抗规则冲突 → 以 ROE/指挥部为准
- 与其他材料冲突 → 护网规则优先（见 `authorization-scope.md`）

---

## 8. 一句话

**开工读线程必读，动作前该报备就报备，节点主动同步但不空等，交付必带证据与迭代。**
