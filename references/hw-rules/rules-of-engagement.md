# 护网交战规则（ROE）与禁止项

> 目的：在不影响生产、不越界、不造成真实损害的前提下完成靶标。

---

## 1. 允许 / 禁止总表

| 类别     | 允许（授权 + ROE 内）          | 禁止 / 需报备                             |
| -------- | ------------------------------ | ----------------------------------------- |
| 扫描     | 定向探测、清单内端口/路径      | 全量暴力扫描、大并发、压测式扫描          |
| 漏洞验证 | 无害 payload、读取少量数据证明 | 拖库、批量导出、删改数据                  |
| 写操作   | 改自己能改回去的测试字段       | 改/删他人数据、改业务状态、真实资损       |
| 上传     | 传测试文件、证明可执行         | 传破坏性 payload、留 webshell 不报备      |
| 认证     | 测自己的会话、换 id 验证越权   | 登出/注销用户会话、批量撞库、爆破生产账号 |
| 内网     | 按靶标路径横向、最小必要       | 无差别横向、碰无关系统、批量提权          |
| 持久化   | 报备后最小化留存               | 未报备后门、rootkit、隐藏账号             |
| 社工     | 仅 ROE 明确允许时              | 钓鱼、电话社工、冒充、攻击个人            |
| 供应链   | 仅授权范围内                   | 攻击第三方厂商、投毒、污染公共仓库        |
| 数据     | 证明性读取、脱敏留存           | 真实个人信息批量留存、外传、公开          |
| 破坏     | 无                             | DoS/DDoS、勒索、删库、破坏证据            |

---

## 2. 扫描与探测节奏

- **先探针后扫描**：先发 5～10 个随机路径判断 404/403 模型，再决定扫不扫
- **限速**：按 ROE 设并发与速率；默认低速率、单线程/少线程
- **时间窗**：不在业务高峰做扫描；夜间行动按排班
- **告警意识**：大面积扫描会触发蓝队封禁，暴露攻击意图；优先定向、低特征
- **被封处理**：换出口/降速/停扫，先判断是否已被监测，报备后再决定

---

## 3. 写操作与业务影响

**先问三句：**

1. 这个写操作会影响生产数据吗？
2. 能改回去吗？
3. 需要报备吗？

**规则：**

- 只改“自己能改回去”的测试字段；改完立刻改回
- 改密/改绑：拿掉旧验证看是否通过即可；过了立刻改回；改不回就停在回包，不留下新密码/新邮箱
- 不扣钱、不清库存、不真实退款、不真实发货
- 多步流程只跳到“证明可跳”为止，不完成真实业务
- 并发测试只打一枪，不持续压

---

## 4. 内网约束

- 只沿靶标路径横向；不碰与靶标无关的系统
- 不提权到非必要权限；不批量收集凭据
- 域渗透高风险动作（DCSync、黄金票据、改域策略）**先报备**
- 不修改 AD/GPO/信任关系；不删除账号；不改密码（除非报备且可恢复）
- 不安装远控/后门到非靶标主机
- 内网数据只做“证明性读取”，不外传、不批量留存

---

## 5. 后门与持久化

- **能不留下就不留**
- 必须留（如维持访问）→ 先报备，登记：主机、方式、账号、文件、清理方式
- 禁止 rootkit、隐藏账号、修改系统关键文件
- 行动结束按指挥部要求清理；清理结果写入 `协同\清理记录.md`
- 未报备后门 = 严重违规

---

## 6. 社工 / 钓鱼 / 近源

- 仅当 ROE 明确允许，且限定目标与话术
- 不冒充执法/监管；不攻击个人隐私；不诱导真实转账
- 钓鱼样本不含真实恶意代码；凭证回收后按规则处理
- 近源（WiFi/门禁/办公网）需单独授权，不在默认范围

---

## 7. 供应链 / 第三方

- 默认不碰第三方厂商、开源仓库、云厂商基础设施
- 若靶标依赖第三方组件，只做“版本/配置”层面的验证，不攻击第三方
- 发现供应链入口 → 上报，由指挥部决定是否扩大授权

---

## 8. 蜜罐与反制

- 遇到疑似蜜罐：先识别（见 `references/vulns/honeypot-recognition.md`），不深挖、不投毒、不上传真实工具
- 不针对蓝队个人/设备做反制
- 蓝队反制仅在授权与规则允许范围内

---

## 9. 数据与证据

- 只读取证明所需的最少数据
- 个人信息、凭据、内网地址：脱敏后入报告；原始证据加密存放
- 禁止外传、公开、用于非行动目的
- 行动结束后按规则销毁/移交

---

## 10. 清理

| 对象                | 动作                       |
| ------------------- | -------------------------- |
| 上传文件 / webshell | 删除；无法删除则报备并登记 |
| 新建账号 / 后门     | 删除；无法删除则报备       |
| 修改的配置/数据     | 恢复原值；无法恢复则报备   |
| 本地工具/脚本       | 清理或归档到任务根         |
| 浏览器会话/凭据     | 按凭证管理规则处理         |
