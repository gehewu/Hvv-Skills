# 留痕、证据与凭证管理

> 护网成果 = 权限 + 证据链。没有证据的“打穿了”在复盘和计分时等于没打。
> 同时：证据里最容易泄露的是凭据和会话，必须单独管理。

---

## 1. 每个动作的最小留痕字段

| 字段     | 说明                                             |
| -------- | ------------------------------------------------ |
| 时间     | 精确到秒，统一时区（建议 UTC+8）                 |
| 操作人   | 本人 / 小组                                      |
| 目标     | 完整 URL / IP:端口 / 主机名                      |
| 动作     | 探测 / 验证 / 利用 / 提权 / 横向 / 取证          |
| 工具     | 手工 / Burp / sqlmap / MSF / 自写脚本            |
| 输入     | 关键参数 / payload（可脱敏，但原始值存加密台账） |
| 结果     | 状态码、关键回显、执行结果                       |
| 证据编号 | 对应 `证据\` 下的文件                          |
| 影响     | 是否触碰生产、是否需报备                         |

落盘：`日志\操作时间线.md`（追加写，不改历史）。

---

## 2. 证据类型与要求

| 类型           | 要求                                                       |
| -------------- | ---------------------------------------------------------- |
| HTTP 请求/响应 | 完整原始包（含 Host、Cookie 占位、body）；响应保留关键字段 |
| 命令执行       | 命令 + 回显 + 主机名/用户 + 时间                           |
| 截图           | 含地址栏/主机名/时间；关键页面全屏                         |
| 文件           | 原始文件 + SHA256 + 来源路径                               |
| 权限证明       | `whoami` / `id` / `ipconfig` / 域信息 + 时间         |
| 数据证明       | 少量样本（脱敏），证明“能读到”即可，不批量留存           |
| 路径图         | 入口 → 跳板 → 目标，标注每跳证据编号                     |

**证据编号：** `E-{靶标}-{序号}`，在报告与时间线中引用。

---

## 3. 证据链

- 入口证据 → 利用证据 → 权限证据 → 横向证据 → 目标证据，逐跳可追溯
- 每跳至少：请求/响应或命令回显 + 时间 + 目标
- 不把“推测”写成“证据”；推测单独标 `待验证`
- 证据不完整时，报告里明确写“未取得完整证据”，不编造

---

## 4. 凭证管理（重点）

**分级：**

| 级别      | 内容                            | 存放                                                                    |
| --------- | ------------------------------- | ----------------------------------------------------------------------- |
| L1 会话类 | Cookie、token、session、JWT     | **不落盘明文**；需要时放内存/临时环境变量；报告只写“已获取会话” |
| L2 账号类 | 用户名/密码、AKSK、私钥、连接串 | 加密台账 `内网\凭据台账.enc`；报告脱敏                                |
| L3 线索类 | 疑似密钥、盐、加密参数          | 可入证据，但报告脱敏                                                    |

**硬规则：**

- 实时会话 token 不写磁盘、不写临时文件、不进对话记录
- 凭据台账统一加密（建议 age/GPG/7z 加密），密码单独保管
- 报告、日报、协同消息里不出现完整凭据
- 凭据“可用”判定：假值对照 → 生产认了 → 认钥枪带出身份或列表；三问有一否 → 只算线索
- 行动结束按规则移交/销毁

---

## 5. 敏感信息

- 手机号、身份证、邮箱：原样保留
- 密码/token/密钥：原样保留
- 内网 IP：原样保留
- 个人信息：只留证明所需的少量样本
- 截图：原样保留

---

## 6. 本地卫生

- 工具、脚本、扫描结果放任务根，不散落桌面
- 不把目标数据同步到个人网盘/公开仓库
- 浏览器保存的账号密码按规则处理，不导出
- 行动结束后清理临时文件、shell 历史中的敏感命令（按规则）

---

## 7. 交付格式

- 正式报告引用证据编号，不直接贴大段原始包
- 原始证据单独打包加密，附清单（文件名、SHA256、说明）
- 日报只写结论与阻塞，不贴凭据
- 复盘材料脱敏后再分享

---

## 8. 一句话

**动作有记录、结论有证据、证据有编号、凭据加密不落明文。**
