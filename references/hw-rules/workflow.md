# 护网工作流：靶标闭环与进站节奏

> 本文件定义护网的靶标闭环与进站节奏。
> 冲突时以本文件 + `hw-rules/` 为准。

---

## 1. 靶标闭环（硬）

```
取一个靶标 T（按优先级）
  → 展开资产：子域/端口/目录/证书/被动DNS/影子资产
  → 去重 → 去废 → 去非存活
  → 剩下的活面全部进站（§2 固定动作）
  → 每个站过“本轮完成”闸（§4）
  → T 达成 / 确认不可达 / 窗口结束 → 标 done
  → 才取下一个靶标
```

**禁止：**
- 清单里所有靶标一次扫完再回头挖
- 靶标还剩活面就去扩新靶标（扩面假进度）
- 用 FOFA 条数/探活计数当进度

**允许：**
- 同一靶标内多线程：深挖为主，禁止全员测绘
- 优质资产回灌：新发现的同靶标业务根域，落盘待本靶标挖完后处理
- 配额尽/工具挂：挖已入库资产，不停工

---

## 2. 进站固定动作（每个活面）

1. **说清这摊（3～5 行）**
   - 谁在用（C 端/商家/运营/管理员）
   - 核心对象（订单/工单/券/文档/账号）
   - 钱、权、状态落在哪几个字段
   - 未登录能碰到哪一层

2. **抽 JS 钥匙**
   - `/api/` 路径、Swagger/OpenAPI、前端路由
   - 签名盐、硬编码钥、密文 id、公钥
   - hidden/admin 路由、演示号、测试租户
   - 执行类 Sink：命令/模板/表达式/文件转换/RPC/Agent 工具
   - 没有写“无”，不发明参数

3. **建接口清单**
   - 抓包补全 METHOD / 参数 / 鉴权
   - 回包里的 id/url/token/内部 host 立刻入队
   - 列表过了，附件/导出再打一枪

4. **全类型矩阵**
   - 未授权、越权/IDOR、注入、SSRF、XSS、RCE、上传、穿越、认证接管、逻辑、凭证、敏感路径
   - **CORS 不挖**
   - 有入口打完；无入口 N/A + 原因（禁止空话）

5. **四件套打在有差分面上**
   - 注入：能看出条数/内容变化、会拉 URL 的参；按栈选探针（SQL/JSON 操作符/ES/HQL/SpEL/SSTI）
   - SSRF：URL/回调/webhook/file/fetch/import/preview/proxy
   - XSS：回显点 + 可写点（存储）
   - RCE：命令/模板/反序列化/危险上传/调试执行
   - **禁止每个 path 喷 `'` 充数**

6. **有会话**
   - 对象图：列表 → 详情 → 附件/导出/审批，每层换 id
   - 换 id 不限字段名；邻号/回包抄的/`0`/`-1`/空
   - 写接口加 role/isAdmin/amount/status/vip（只改能改回去的）
   - 多步流程跳步；领取/库存/券/审核并发一枪

7. **同闸停**
   - 业务口全是同一登录码、未登录例外已点过 → 四件套收口
   - sibling 一眼差分：有新 path/新回码才升级
   - 不在同皮/同闸上磨

8. **肥瘦分层**
   - 肥面（JS 多/后台/业务 JSON）：深挖，建对象图
   - 瘦壳（403/同闸/同皮/无业务 script）：一眼证伪，记过换下一条

---

## 3. 力气顺序（护网版）

1. 未登录出他人/他主体（读名单/详情/附件）
2. 认证接管（发会话/重置/改绑/换票/2FA）
3. 换 id（没号：未授权通了再换；有号：带会话换）
4. 四件套（注入/SSRF/XSS/RCE）打在业务参上
5. 凭证/敏感路径（配置/AKSK/swagger/actuator/heapdump）
6. 逻辑/提权（加字段/跳步/并发）
7. 其他现场面（GraphQL/WebSocket/上传/XXE/反序列化）

> 高价值苗头（稳定注入/RCE/跨租户/可用凭证/任意登录进号）先打穿再换目标。

---

## 4. 单站“本轮完成”闸

1. 这摊已说清（或确认抽不出业务对象）
2. 接口清单已建（含 JS 钥匙表，无则写“无”）
3. 类型矩阵探针勾完（有入口打，无入口 N/A + 原因）
4. 有差分面的四件套真发过 payload 或证伪
5. 有会话：对象图/换 id/加字段打过
6. 认证口勾完或 N/A
7. 确认成果已按 `report-format.md` 落盘
8. 未耗在同皮镜像/已 covered 面

满足即可换站；靶标所有活面过闸 → 靶标 done。

---

## 5. 空转与时间盒

| 信号 | 处置 |
|------|------|
| 15～20 分钟无成果苗头，只见 403/health/重复 path | 瘦壳杀线，换本靶标下一条活面 |
| 肥面还在抽 JS/建对象图 | 算干活，不算空转 |
| 报告不增、只在测绘 | 回未完成站，补矩阵 |
| 同皮/同闸反复磨 | 停，一眼差分，换面 |
| 被硬封锁 | 换入口/旁路；无则记 blocked，换靶标 |

**不算进度：** 测绘条数、探活计数、每个 path 喷 `'`、把已有洞再确认一遍、CORS。
**算进度：** 说清这摊、接口清单、回包线索入队、有差分面的四件套、换 id、成果落盘。

---

## 6. 多线程

| 角色 | 做什么 | 禁止 |
|------|--------|------|
| 深挖线程（多数） | 指定靶标/资产：清单 → 矩阵 → 成果 | 单独开测绘当主业 |
| 补面线程（少量） | 下一优质资产/同簇带出 host | 与深挖线程同时狂刷测绘 |
| 主控 | 范围、报备、队列、汇总 | — |

- 测绘由主控短触发；结果入队后线程立刻回深挖
- 禁止 N 条线程都在测绘/探活，0 条在建清单
- 子线程交付必须含证据、阻塞、迭代

---

## 7. 自检

- [ ] 是否在打清单内靶标？有没有扩面到清单外？
- [ ] 靶标内活面是否都过了“本轮完成”闸？
- [ ] 有没有把“未授权读”当终点？
- [ ] 有差分面的四件套真打了吗？
- [ ] 有会话时换 id/对象图打了吗？
- [ ] 中危同一对象升链了吗？
- [ ] 是否在同皮/同闸上磨？
- [ ] 成果是否落盘、证据是否编号？
- [ ] 高风险动作报备了吗？节点同步了吗？

---

## 8. 一句话

**一个靶标闭环：展开 → 清洗 → 进站 → 过闸 → 换靶标；先拿权限，再写报告。**
