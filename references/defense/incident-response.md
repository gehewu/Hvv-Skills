# 蓝队：应急响应与溯源

> 目标：发现 → 隔离 → 取证 → 清除 → 恢复 → 复盘。
> 原则：**先止损、再取证、后清除；不破坏证据、不擅自对外披露。**

---

## 1. 响应流程

### 1.1 发现与确认
- 来源：告警、用户报告、红队通报、巡检
- 确认：是否真实、影响范围、是否仍在活动
- 立即上报，启动响应

### 1.2 隔离（止损）
- 网络隔离：封 IP/域名、下 ACL、断网（谨慎，避免打草惊蛇）
- 主机隔离：下线/隔离、禁用账号、停服务
- 账号：禁用/改密/吊销会话
- 保留现场：不要先重装/删除

### 1.3 取证
- 主机：进程、网络连接、账号、计划任务、服务、启动项、文件、日志
- 流量：PCAP、DNS、代理日志
- 应用：访问日志、错误日志、数据库日志
- 内存/磁盘镜像（按需）
- 证据链：时间、来源、哈希、保管人

### 1.4 清除
- 删除 webshell/恶意文件/账号/计划任务/服务
- 修复入口（漏洞/弱口令/配置）
- 确认无残留、无二次入口

### 1.5 恢复
- 恢复业务、验证功能
- 加强监控、观察复发
- 通知相关方

### 1.6 复盘
- 时间线、根因、影响、处置得失
- 改进项：技术、流程、监控、预案
- 更新资产/风险台账

---

## 2. 溯源

### 2.1 攻击者画像
- IP/ASN/归属、代理/VPN/Tor
- 域名/证书/基础设施
- 样本哈希、C2、TLS 指纹、UA
- TTP：入口、工具、横向、持久化

### 2.2 溯源方法
- 日志关联：入口 → 横向 → 外连
- 样本分析：静态/动态、字符串、配置
- 基础设施关联：被动 DNS、证书、favicon、WHOIS
- 蜜罐/沙箱诱捕

### 2.3 反制边界
- 仅在授权与 ROE 允许范围内
- 不攻击攻击者个人设备/第三方
- 不公开披露未授权信息
- 反制成果交指挥部

---

## 3. 常见事件处置要点

| 事件 | 关键动作 |
|------|----------|
| Webshell | 定位文件、进程、入口；删文件、修入口、查横向 |
| 勒索 | 隔离、断网、取证、评估备份、不轻易付赎 |
| 数据泄露 | 止损、确认范围、取证、通知、合规上报 |
| 账号接管 | 禁用、改密、吊销会话、查 MFA/登录日志 |
| 挖矿 | 定位进程、清除、修入口、查横向 |
| C2 | 封域名/IP、定位进程、查持久化、全网排查 |

---

## 4. 交付

- 事件报告：时间线、根因、影响、处置、证据
- 溯源报告：画像、IOC、基础设施、TTP
- 整改清单：问题、责任、期限、验证
- 复盘报告：改进项

---

## 5. 一句话

**先止损、再取证、后清除；证据不破坏，对外不擅自披露。**
