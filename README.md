# hvv-skills — 护网行动技能包

> 面向护网（HVV / 攻防演练 / 红蓝对抗）的全流程技能：**红队打点 + 内网横向 + 蓝队防守 + 授权/留痕/协同/报告**。
> 漏洞知识统一放在 `references/vulns/`；规则、测绘、内网、蓝队、工具各自独立。

---

## 1. 这套技能覆盖什么

| 模块 | 内容 |
|------|------|
| 红队外网 | 资产测绘、外网打点、边界设备、Web/API 漏洞矩阵、认证接管、凭证 |
| 红队内网 | 提权、凭据、横向、域渗透、免杀与低特征 |
| 蓝队防守 | 资产自查、暴露面收敛、告警研判、应急响应、溯源、整改复测 |
| 行动规则 | 授权范围、ROE、留痕、凭证管理、协同报备、报告格式 |
| 漏洞知识 | 注入、XSS、SSRF、XXE、越权、上传、穿越/LFI、WAF、逻辑/竞态、CSRF、HTTP 协议、GraphQL、JWT/OAuth、反序列化、子域接管、信息泄露等 |

护网、HVV、攻防演练、红蓝对抗、护网红队/蓝队、值守、靶标、攻打目标、护网自查、迎检、暴露面收敛、应急溯源。

### 开工三件事
1. 说角色：红队 / 蓝队 / 自查
2. 给范围：授权书、靶标清单、时间窗口
3. 说交付：日报 / 成果报告 / 整改清单 / 复盘

### 典型用法
```
用 hvv 技能，我是红队，靶标清单在 xxx，时间窗口 xxx，先做资产测绘

用 hvv 技能，帮我按护网格式写这次行动的报告
```

## 5. 硬规则（摘要）

1. **授权清单唯一**：只打清单内；越界/存疑立即停手上报
2. **ROE 优先**：不 DoS、不拖库、不删改生产、不未报备后门、不违规社工、不攻击供应链、不真实资损
3. **全程留痕**：时间/目标/工具/payload/结果/证据编号
4. **凭证管理**：加密台账；实时会话 token 不落盘明文；报告脱敏
5. **协同报备**：提权/横向/后门/核心系统先报备；靶标达成/被封/范围存疑立即同步
6. **生产影响最小**：能读不写、能小不大、能少不多、能停不冲
7. **报告口径**：只认 `references/hw-rules/report-format.md`
8. **清理**：行动结束按指令清理；后门必须登记

详见 `references/hw-rules/`。

## 6. 红队 / 蓝队主线

### 红队
```
接令建账 → 资产测绘 → 外网打点 → 边界突破 → 内网横向 → 成果固化 → 复盘
```
- 靶标闭环：一个靶标的面挖完再换下一个
- 优先：未登录他主体 → 认证接管 → 换 id → 四件套 → 凭证/敏感路径
- 先拿权限，再写报告

### 蓝队
```
资产自查 → 暴露面收敛 → 告警研判 → 应急响应 → 溯源反制 → 整改复测
```
- 只检测不利用（除非另有授权）
- 先止损、再取证、后清除

## 7. 维护

- 每次行动后复盘：可复用打法写进 `references/vulns/手法索引.md`
- 踩坑/封禁/告警教训写进 `references/hw-rules/rules-of-engagement.md` 教训区
- 规则冲突：护网规则优先；现场证据优先于文档
- 只增强，不封顶：清单没写的攻击面照样打
